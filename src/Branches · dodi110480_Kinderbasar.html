        Design-Philosophie

        Das Design basiert auf drei Kernprinzipien:

        Prinzip Beschreibung
        Glassmorphism Semi-transparente Oberflächen mit backdrop-blur erzeugen Tiefe und Eleganz
        Luftigkeit Großzügige Abstände, helle Farben und weiche Ränder lassen die UI atmen
        Kontrast Klare Hierarchie durch sichtbare Ränder, definierte Schatten und dunkle Texte

        Do's ✅

        • Großzügige Padding- und Margin-Werte verwenden
        • Sanfte Übergänge und Hover-Effekte nutzen
        • Farbige Akzente sparsam und konsistent einsetzen
        • Backdrop-Blur auf glasigen Elementen verwenden
        • Subtile Animationen für Interaktivität

        Don'ts ❌

        • Harte Ränder oder eckige Kanten (immer abgerundet!)
        • Knallige, unharmonische Farben
        • Zu viele Animationen gleichzeitig
        • Opake, schwere Hintergründe
        • Texte mit zu wenig Kontrast

        Farbpalette

        Hintergrund

        --bg-base: #f0f4fa;           /* Leichtes Blaugrau als Basis */
--bg-subtle: #e8edf5;          /* Noch etwas dunkler, für Sektionen */

        Der globale Hintergrund verwendet zusätzlich radiale Gradienten für Tiefenwirkung:

        background-image:
  radial-gradient(ellipse 80% 60% at 50% -20%, rgba(99, 102, 241, 0.1), transparent),   /* Indigo oben */
  radial-gradient(ellipse 60% 50% at 80% 50%, rgba(139, 92, 246, 0.07), transparent),    /* Violet rechts */
  radial-gradient(ellipse 60% 50% at 20% 80%, rgba(16, 185, 129, 0.05), transparent);    /* Emerald unten-links */

        Primärfarben (Indigo-Palette)

        Name Tailwind Hex Verwendung
        Primary indigo-600 #4f46e5 Buttons, Links, Hauptakzente
        Primary Light indigo-500 #6366f1 Hover-States, Glow-Effekte
        Primary Subtle indigo-50 #eef2ff (mit /80 opacity) Icon-Hintergründe, Badges
        Primary Border indigo-100 #e0e7ff (mit /60 opacity) Ränder auf Primary-Elementen

        Akzentfarben

        Farbe Tailwind Hex Verwendung
        Emerald emerald-600 #059669 Erfolg, Live-Status, Umsatz
        Amber amber-600 #d97706 Warnungen, Deadlines, Schritt 3
        Purple purple-600 #9333ea Dokumente, Downloads, Schritt 2
        Pink pink-600 #db2777 Herzen, Danke-Sektionen
        Red red-500 #ef4444 Fehler, Abmelden, Ausgebucht

        Name Tailwind Hex Verwendung

        Animationen

        Keyframes (Tailwind Config)

        Animation Klasse Dauer Beschreibung
        Float animate-float 8s Sanftes Schweben auf/ab
        Float Slow animate-float-slow 12s Langsameres Schweben
        Float Slower animate-float-slower 16s Sehr langsames Schweben
        Fade In animate-fade-in 0.6s Einblenden
        Fade In Up animate-fade-in-up 0.6s Einblenden + von unten gleiten
        Slide Up animate-slide-up 0.5s Von unten reinsliden
        Scale In animate-scale-in 0.4s Einzoomen
        Shimmer animate-shimmer 2.5s Pulsierendes Leuchten (LIVE-Badge)

        Gestaffelte Animationen

        Für kaskadierende Einblendeffekte animationDelay verwenden:

        <div className="animate-fade-in-up">
  {/* Erste Element (sofort) */}
</div>
<div className="animate-fade-in-up" style={{ animationDelay: '0.1s' }}>
  {/* 100ms verzögert */}
</div>
<div className="animate-fade-in-up" style={{ animationDelay: '0.2s' }}>
  {/* 200ms verzögert */}
</div>
